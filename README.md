# AnchorFX — Institutional FX & Yield Protocol

AnchorFX is a decentralized foreign exchange (FX) and liquidity protocol built on Arc Network. It provides sub-second stablecoin swaps (USDC / EURC), smart contract-enforced subscriptions, and AI agent payment integration.

## Key Features

- **Deterministic Finality:** Sub-400ms settlement times powered by Arc Network.
- **Predictable Gas Fees:** Flat ~$0.01 gas fee paid natively in USDC.
- **On-Chain Subscriptions:** Automated USDC/EURC recurring payments without chargebacks.
- **Agentic Commerce Ready:** Designed for autonomous AI agents via custom API & MCP server interfaces.
