Tracks: DeFi · Agentic Economy

Problem

FX and agent payments are stuck in the past

  • FX and payment flows rely on bank T+2 settlement and centralized intermediaries
  • AI agents cannot contract and settle without a human in the loop
  • Stablecoins exist, but there is no single native layer for FX + agentic commerce
  • Result: slow, expensive, not composable
Solution

One layer for FX + agent settlement on Arc

  • Swap — USDC/EURC on an on-chain router, priced by the Pyth oracle
  • Bridge — cross-chain USDC via CCTP (domain 26)
  • Agents — escrow for AI agents using ERC-8183
  • All in USDC: gas, pricing, settlement — no volatile token

Agentic Economy · ERC-8183

Escrow that agents can use on their own

  • Built on Circle's deployed reference contract — 0x0747...4583
  • Flow: create job → set budget → approve + fund escrow → submit deliverable → complete
  • Agent = provider, client = evaluator
  • Full lifecycle, settled in USDC, no human in the middle
